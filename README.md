# COFOCO — Conscious Form Company (Design 2: Architectural Specimen Edition)

Character-calibrated equipment capsules and somatic restoration implements. Designed with strict structural utility, zero ornamental decoration, and unbending tactile fidelity.

## Features
- **06 Mythic Archetypes**: Arjun, Bheema, Karna, Sita, Draupadi, and Savitri.
- **08 Equipment Capsules**: Complete with multi-item Bill of Materials (BOM), dimensions, and weights.
- **Pure Native Scrolling**: Zero motion libraries, instant 80ms CSS transitions, 60fps native speed.
- **Indian Commerce & Taxes**: 18% GST tax-inclusive calculations, ₹999 free-shipping threshold, and Indian postal code validation.
- **Operations & Fulfillment Command Center (`/admin`)**: 4-step order dispatch stepper, interactive physical pick list checklist, component inventory ledger, and exception case queue.
- **Founder Analytics Cockpit (`/analytics`)**: 6 KPI commercial metric cards, 14-day daily sales velocity bar graph, "What-If" conversion simulator slider, archetype revenue attribution, and one-click CSV export.

## Tech Stack
- React 18 + TypeScript (Strict)
- Vite + CSS Modules + CSS Custom Properties
- Pure Native CSS Transitions (Zero Framer Motion overhead, lightweight ~300 kB bundle)
